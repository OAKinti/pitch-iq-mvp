Owner decision D-9A (Nov 24): Supabase anonymous sign-in on first launch; every write uses `auth.uid()`; age bracket and consents are persisted server-side (and locally) so the age gate cannot be retried after a restart. Migration 004 (already committed on this branch) enforces the server side; read it first: `supabase/migrations/004_security_hardening.sql`.

## Why (D7.2 High H-auth)
`DEMO_USER_ID = 'demo-you'` is used for every write and the app never signs in, so outside Demo Mode every RLS-protected insert fails and the error is swallowed (`AppStateContext.tsx` `.catch(() => undefined)`); consent (BIPA written release) and age live only in memory.

## Behaviour
1. `AppStateProvider` calls `auth.ensureSession()` once on mount; `userId` comes from the session (Demo Mode: `DEMO_USER_ID`). Writes wait for the session; with no session they are queued in memory and flushed when one appears (keep it simple: retry once on the next successful `ensureSession`).
2. No silent swallowing: failed writes set `syncStatus` (`'offline' | 'error'`) exposed on the context; log nothing that contains user data.
3. Age bracket + consents are written to `localProfile` immediately and to the server via `saveProfile` / `recordConsent` once a session exists. On restart, a persisted age bracket locks the age step; under-13 stays private (existing defaults).
4. D-9C on the client: when `ageBracket === 'under_13'` and the profile is not parent-verified, the VoiceCoach is created with `transport: null` (template debrief; no request leaves the device). The server enforces the same (voice_tier2_status).
5. code-scout Mediums (same file): (a) a debrief that resolves after a newer `completeDrill` must not overwrite the newer debrief (request token); (b) `completeDrill` is idempotent per drill result id (double-tap `drill-view-results` saves once).

## Contract clauses (add to your tests by name)
- AUTH-1 ensureSession signs in anonymously once and reuses the persisted session; never throws.
- AUTH-2 every repository write uses the session user id; `'demo-you'` is never sent to Supabase.
- AUTH-3 write failures surface as `syncStatus`, never silently dropped.
- AUTH-4 a persisted age bracket locks the age gate across restarts; first run inputs are empty.
- AUTH-5 `recordConsent` refuses `parental_verified` client-side.
- COPPA-1 under-13 unverified => VoiceCoach transport null.
- RACE-1 stale debrief never overwrites a newer drill's debrief; RACE-2 completeDrill idempotent.
