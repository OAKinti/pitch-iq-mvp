## Steps
1. `contrast.test.ts`: a test-local `relativeLuminance` / `contrastRatio` (WCAG 2.1: sRGB linearization with the 0.03928 knee, `(L1 + 0.05) / (L2 + 0.05)`). The pair table names tokens (`['textMuted', 'surfaceHigh']`), never hex. Tables are exactly those in A11Y-1. Fail the test if a token does not resolve to `#RRGGBB`.
2. `HudPrimitives.tsx`: `const reduced = useReducedMotion()` (from `react-native-reanimated`). Reduced: `HudButton` press handlers leave `scale` at 1; `HudToggle` sets `knob.value = value ? 1 : 0`; `StatBar` sets `fill.value = pct`. Not reduced: unchanged.
3. `reduceMotion.test.tsx`: override the Reanimated mock in this file only - `jest.mock('react-native-reanimated', () => ({ ...require('react-native-reanimated/mock'), useReducedMotion: jest.fn(), withTiming: jest.fn((v) => v), withSpring: jest.fn((v) => v) }))` (adjust to the mock's real export shape, keeping its default export). Assert call counts for both settings.
4. `GroupSessionScreen.tsx`: in the own row, render the rank with `colors.textSecondary` (a `rankMe` style); other rows keep `textMuted`. `contrastUsage.test.tsx` renders the screen with the demo repository, finds `leaderboard-row-<DEMO_USER_ID>`, flattens each child Text style and checks its color is one of `textPrimary`, `textSecondary`, `accent`.
5. `HighlightShareScreen.tsx`:
   - Read `ovr`, `badges`, `ageBracket` from `useAppState()`. When `ovr` exists, render `<OvrSticker ovr={ovr} badges={badges} />` in a `HudPanel` titled "Sticker".
   - Replace both `process.env` reads and the placeholder ids with `getShareConfig()` (memoized). `share-summary` shows the target label and either "native handoff configured" or "OS share sheet fallback"; keep the "Native handoff ships Day 6 (dev build)" line.
   - `ageBracket` null or `under_13`: every `share-<target>` button disabled and a `share-age-locked` notice ("Sharing is off for under-13 profiles.").
   - Do not call `createStickerCapture` or `createSocialHandoff` here; that is D6.2 device wiring.
6. `highlightShare.test.tsx` and the `results.test.tsx` block: cover UI-2, SEC-17 and the SEC-15 grep (no `process.env`, `demo-app-id` or `demo-client-key` in `src/screens` or `src/components`). Seed an adult with `initial: { ageBracket: 'adult_18_plus' }` where a share press is expected.
7. Maestro flows (YAML only; nothing is run here):
   - `pose-telemetry.yaml`: onboarding as in `mvp-smoke.yaml`, start a simulated Ball Mastery drill, `assertVisible` `skeleton-overlay`, `telemetry-fps`, `pose-source`.

   - `under13-share-locked.yaml`: onboarding with a birth year that classifies as under 13 (follow the existing onboarding testIDs for the parental step), reach the share screen, `assertVisible` `share-age-locked`.
   - All flows: `appId: com.pitchiq.mvp`, ids only (no text selectors).
8. `maestroFlows.test.ts`: read `.maestro/*.yaml` and non-test `src/**/*.tsx` with `fs`; collect testID literals and template prefixes (`share-${...}` -> `share-`); check UI-1.
