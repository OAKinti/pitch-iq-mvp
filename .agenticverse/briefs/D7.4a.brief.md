## Notes
- `jest` roots are `<rootDir>/src`, so the test must live under `src/__tests__/`.
- The camera string is currently identical in `infoPlist`, the `expo-camera` plugin and the `expo-mediapipe-pose` plugin, and the microphone string in `infoPlist`, `expo-camera` and `expo-audio`; REL-3 locks that in.
- `android.permissions` must stay exactly `["android.permission.CAMERA"]`; `RECORD_AUDIO` is added by the `expo-camera` plugin (`recordAudioAndroid: true`) for clip audio and must not be blocked.
- SEC-20 patterns: `sk-ant-`, `service_role`, `xi-api-key`, `eyJ` followed by 10 or more base64url characters. Allowlisted `EXPO_PUBLIC_*` names: `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `DEMO_MODE`, `FACEBOOK_APP_ID`, `TIKTOK_CLIENT_KEY`. Write the checklist so it does not trip its own check (name `SUPABASE_SERVICE_ROLE_KEY` in upper case; the pattern is lower-case `service_role`).
- Do not run `eas` commands (no account, no token here) and do not run `expo prebuild`.
- `npx expo config --type public` is a quick local sanity check that `app.json` still parses; it needs no network.
